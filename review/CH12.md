# CH12 저자 검토 자료 — 결과 검증과 오류 해결

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH12.md`
작성자 자체 검토 반영(2026-10-26, Phase 3D). 저자 승인 전이며 학습자 시험은 하지 않았습니다.

> CH09의 기초 사실 확인과 겹치지 않도록 이 장은 *반복 가능한 검증 절차(체크리스트), 판단 기준, 오류 기록*에 집중했고, 사실·추론·가정·미확인 구분은 CH09 복습 한 절로 줄였습니다. 필수 실습은 AI 서비스 없이 가능하며 실습 5만 선택입니다. 이 장은 공식 문서를 인용하지 않습니다.

## 1. 장별 핵심 주장

1. AI는 틀릴 수 있고 지침서가 있어도 어길 수 있으므로 매번 같은 절차로 검증해야 한다. (일반 설명)
2. 결과 → 원문(지어냄 찾기)과 원문 → 결과(누락 찾기)의 양방향 대조를 한다. (저자 제안)
3. 숫자·날짜·인물·출처를 항목별로 검증한다. (저자 설계)
4. 재실행·직접 수정·확인 요청의 판단은 심각도와 반복 가능성으로 정한다. "2회까지 재실행" 권고는 시험하지 않았다. (저자 제안)
5. 오류는 한 줄씩 기록하고 월 1회쯤 유형별로 집계해 CH10 개선 목록으로 올린다. (저자 제안, 시험하지 않음)
6. 이 장은 CH01 진단 Q4("확인 기준을 적어 둔 것이 있다")에 대한 문서 답이다. 정확도를 높인다는 것은 검증하지 않았다.

## 2. 교육목표

검증 이유, 양방향 대조, 항목별 검증, 누락·형식 오류·근거 없는 생성 식별, 재실행 판단, 오류 기록과 개선, 후보 A 검증 체크리스트와 최종 확인 기록.

## 3. 실습과 완료 기준

| 실습 | 구분 | 하는 일 | 완료 기준 |
|---|---|---|---|
| 1 | 필수 | 검증 체크리스트(CH11 체크리스트 확장) | 양방향 대조, 숫자·날짜·인물·출처, 형식, 금지사항, 항목별 대조 대상 |
| 2 | 필수 | 오류 발견 및 수정 기록(가상 초안 사용) | 오류 6개 이상, 유형·심각도·근거·수정, 누락 |
| 3 | 필수 | 재실행 여부 판단표 | 모든 오류에 조치, 재실행은 고칠 곳 |
| 4 | 필수 | 사람의 최종 확인 기록 | 확인 항목, 남은 확인 필요, 승인자 역할, 최종 판단 |
| 5 | 선택 | 실제 AI로 재실행·검증 | `[실제 AI 실행]`/`[가상 실행]` 표시 |

산출물 4개: 검증 체크리스트, 오류 발견 및 수정 기록, 재실행 여부 판단표, 사람의 최종 확인 기록.

**가상 초안의 오류 8개(검증함, 본문 6절에 해설):** 날짜 10월 31일(원문 30일), 검토자 오류, 지어낸 교육 일정·담당자·지연 사유, 없는 문서 번호 K02, 누락(10월 25일 전화), 형식 오류.

## 4. 출처가 필요한 주장

공식 문서·하네스 사례 인용 없음. 모두 일반 설명 또는 저자 해석입니다.

| 주장 | 비고 |
|---|---|
| 양방향 대조, 심각도 3단계, 재실행 판단 기준, 오류 기록 양식 | 저자 설계. 외부 기준 아님 |
| AI가 원문에 없는 내용을 만들거나 숫자를 틀릴 수 있다 | 일반 설명. 특정 제품의 오류율은 말하지 않음 |
| 가상 AI 초안 | 학습용으로 일부러 틀리게 쓴 것(본문에 표시) |

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | 재실행 2회 한도 권고 | 학습용 임의 기준. 저자 결정 |
| 2 | 심각도 정의 | 시험 후 조정 |
| 3 | CH09와 겹치는 정도(2-2절) | 복습 한 절만 둠. 더 줄일지 저자 결정 |
| 4 | 체크리스트 항목 수가 학습자에게 많은지 | 7절에 "필수 항목만 남기기" 안내를 둠 |
| 5 | 가상 초안 하나로 8개 오류를 모으는 설계 | 실제 AI 오류와 다를 수 있음을 본문에 표시 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간 70분.** 저자의 예상이며 시험하지 않았습니다.
- 미검증: 학습자가 체크리스트를 실제 업무에서 반복해 쓰는지 / 양방향 대조가 누락을 실제로 줄이는지 / 판단표가 합리적인지 / 실제 AI가 가상 초안과 같은 오류를 내는지.

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "CH09와 뭐가 달라요?" | CH09는 한 번의 확인, CH12는 매번 쓰는 체크리스트와 판단·기록 |
| "검증하느라 시간이 더 들어요" | 필수 항목만 남기고 낮은 심각도 점검을 줄인다. 시간은 내가 기록으로 확인한다 |
| "AI가 틀리면 다시 시키면 되죠?" | 원인(입력, 지침서)을 고치고 재실행. 반복되면 사람이 직접 작성 |
| "원문이 틀린 것 같아요" | 원문 작성자에게 확인하고 그동안 "확인 필요" |
| "AI가 없어요" | 가상 초안으로 필수 실습 가능 |
