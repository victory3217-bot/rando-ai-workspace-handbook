# CH06 저자 검토 자료 — ChatGPT 작업환경 구축

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH06.md`
작성자 자체 검토 반영(2026-10-26, Phase 3B). 저자 승인 전이며 학습자 시험은 하지 않았습니다.

> 이 장의 모든 실습은 가상자료만 씁니다. 계정이 없거나 조직 정책상 쓸 수 없으면 설계서와 가상 AI 결과물로 대체하며, 그래도 산출물 5가지가 완성됩니다. **이 책은 ChatGPT 화면을 직접 조작해 시험하지 않았고, 공식 도움말만 읽었습니다.**

## 1. 장별 핵심 주장

1. 프로젝트는 관련 대화, 파일, 지침을 한곳에 모아 두는 기능이다. (공식 S6)
2. 프로젝트 지침은 그 프로젝트 안에서만 적용되고 전역 맞춤 지침보다 우선한다. (공식 S6)
3. 프로젝트 파일 수는 요금제별(Free 5, Go·Plus 25, Edu·Pro·Business·Enterprise 40)이다. (공식 S6)
4. 프로젝트 메모리는 기본/프로젝트 전용이 있고, 학습자에게 프로젝트 전용을 권한다. (공식 사실 + 저자 해석)
5. 개인 계정은 `Improve the model for everyone`이 켜져 있으면 프로젝트 정보가 학습에 쓰일 수 있고, 업무용 워크스페이스는 기본적으로 학습에 쓰이지 않는다. (공식 S6, S1, S2)
6. 프로젝트에 올린 자료에도 CH03의 등급과 규정이 그대로 적용된다. (저자 해석)
7. 프로젝트 목적·지침 양식(역할, 입력, 출력 형식, 규칙, 사람이 확인할 것)은 저자의 교육용 설계이며 AI 결과를 개선한다고 검증하지 않았다.
8. 결과는 원문과 대조해 검증하고, 일부러 틀린 가상 결과물로 검증을 연습한다. (저자의 교육 설계)

## 2. 교육목표

프로젝트 개념, 만들기·설정, 목적과 지침, 허용된 가상자료, 첫 업무 실행과 검증, 무료와 유료·조직의 구분.

## 3. 실습과 완료 기준

| 실습 | 하는 일 | 완료 기준 |
|---|---|---|
| 1 | 프로젝트 목적(CH01 목적 연결) | 목적과 하지 않는 일 |
| 2 | 프로젝트 지침 초안 | 역할, 입력, 출력, 규칙, 확인할 것 |
| 3 | 허용된 가상자료 선정(CH03·CH04·CH05 연결) | 모두 가상, C 없음 |
| 4 | 프로젝트 만들기와 설정 또는 설계서(대체) | 만들었거나 설계서, 공유·외부 연결 없음 |
| 5 | 첫 업무 실행 | 결과물 저장 |
| 6 | 결과 검증 기록 | 대조 결과, 수정, 최종 판단 |

산출물 5개: 프로젝트 목적, 지침 초안, 허용된 가상자료, 첫 업무 실행 결과물, 결과 검증 기록.

**한계:** 한국어 화면의 메뉴 이름, 프로젝트 지침 글자 수 제한, 파일 형식·크기 세부 한도, 요금제 가격·모델 한도, 데스크톱 앱, 조직 워크스페이스 관리자 설정은 읽지 않았고 본문에도 적었습니다. OpenAI 문서는 "Updated: 4시간 전"처럼 상대 날짜만 표시합니다. 문서가 최근 갱신된 상태이므로 **수업 직전에 반드시 다시 읽어야 합니다.**

**저자 해석:** 프로젝트와 CH02 ③·④·⑤ 대응, 프로젝트 전용 메모리 권고, 이 장이 정하는 제한(공유·연결 금지), 가상 AI 결과물의 틀린 곳 해설.
