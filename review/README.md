# 저자 검토 자료 / Author Review Packet

CH01~CH14(필수 과정)를 저자가 검토할 수 있도록 장마다 한 쪽으로 정리한 **작업 문서**입니다. 교재 본문이 아니며 사이트에 게시되지 않습니다(빌드는 `ko/`와 `en/`만 읽습니다).

## 현재 상태

- 14개 장 모두 `Draft`입니다. `last_reviewed`는 비어 있습니다.
- **이 문서를 만든 시점까지 사람의 검토도, 실제 학습자 시험도 없었습니다.** 아래의 "학습 효과"나 "소요 시간"은 모두 저자(작성자)의 예상이며 검증되지 않았습니다.

## 장마다 같은 순서로 적었습니다

1. 장별 핵심 주장
2. 교육목표
3. 실습과 완료 기준
4. 출처가 필요한 주장 (근거가 있는 것 / 근거가 약한 것 / 저자 해석)
5. 저자의 의사결정이 필요한 항목 (작성자의 권고 포함)
6. 예상 실습시간과 미검증 사항
7. 강사용 예상 질문과 오류 대응
8. 저자 검토 결과 (**저자가 직접 작성하는 칸**, 비어 있음)

## 검토가 끝난 뒤에 할 일 (자동으로 바뀌지 않습니다)

1. 장별 8번 칸에 검토 결과를 적는다.
2. 수정이 필요하면 `ko/chapters/CHxx.md`를 고친다.
3. 승인하는 경우에만 `content-manifest.json`의 해당 장 `status`와 `last_reviewed`를 **저자가 직접** 바꾼다. 도구나 AI가 대신 바꾸지 않는다.
4. `CHANGELOG.md`에 검토 사실을 적는다.

## 파일

| 파일 | 내용 |
|---|---|
| `CH01.md` | AI 워크스페이스란 무엇인가 |

| `CH03.md` | AI에 입력할 수 있는 정보와 정보보안 |
| `CH04.md`~`CH14.md` | 각 장의 저자 검토 자료(장 제목은 `content-manifest.json` 참조) |
| `INTEGRATED_REVIEW_PLAN.md` | CH01~CH14 전체 통합 검토 계획(작업 문서, 장 검토 자료 아님) |
| `LAUNCH_PLAN_PUBLIC.md` | 단일 공개 저장소 런칭 계획(보안·공개 점검 A/B/C, 사이트 구성, Pages 공개 단계) |

| `WORKSHOP_6H_PLAN.md` | 6시간 워크숍 핵심 실습 선정안(작업 문서, 시험하지 않은 계획) |
