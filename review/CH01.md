# CH01 저자 검토 자료 — AI 워크스페이스란 무엇인가

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH01.md`

## 1. 장별 핵심 주장

1. AI 워크스페이스는 AI 서비스 하나가 아니라 폴더, 클라우드, AI 서비스, 업무문서, 규칙을 합친 *작업환경*이다. (이 책의 작업 정의)
2. AI를 잘 쓰는 첫걸음은 좋은 질문이 아니라 *자료 정리*다. (저자 해석)
3. 워크스페이스, 워크플로, 하네스는 서로 다른 개념이다. (이 책의 작업 정의)
4. AI가 초안을 만들고 사람이 사실과 결정을 확인하는 구조가 이 책 전체에서 반복된다. (저자 해석)
5. 서버에서 동작하는 AI 서비스에는 입력한 내용이 서비스 회사로 전송된다. (일반 설명, CH03에서 근거를 다룸)

## 2. 교육목표

- AI 워크스페이스를 자기 말로 설명한다.
- 워크스페이스, 워크플로, 하네스를 구분한다.
- 지난 일주일 업무에서 맡길 후보 3가지를 입력과 결과물 한 줄로 쓴다.
- 먼저 손볼 곳 1~2가지를 짚는다.

## 3. 실습과 완료 기준

실습: **개인 업무환경 진단** (3단계, 복사용 양식 4개)

| 단계 | 하는 일 | 완료 기준 |
|---|---|---|
| 1 | 지난 일주일 업무 8개 이상 쓰고 ★ 표시 | 업무 8개 이상 |
| 2 | 후보 3가지의 입력·결과물·사람이 확인할 것 | 후보마다 세 항목이 한 줄씩 |
| 3 | 진단 5문항, 먼저 손볼 곳 | 5문항 답변, 손볼 곳 1~2개 |

스스로 점검: 후보 A를 동료에게 5분 안에 설명할 수 있는가.

## 4. 출처가 필요한 주장

| 주장 | 현재 근거 | 필요한 조치 |
|---|---|---|
| 세 개념의 정의(2-4절) | 내부 기획 문서의 작업 정의. 공개 출처 없음 | 공개 문헌을 검토해 인용하거나, "이 책의 작업 정의"라는 표현을 유지할지 결정 |
| 기존 사무환경 vs AI 업무환경 비교표 | 저자 해석(본문에 표시함) | 저자 확인 |
| "대부분의 AI 서비스는 서비스 회사 시스템에서 동작" | 일반 설명. CH03의 공식 문서가 일부 서비스에 대해 뒷받침 | 표현이 지나치게 일반적이지 않은지 확인 |
| 가상 사례의 시간(40분, 15분, 2시간)과 "환경이 갖춰지면" 모습 | 교육용 가상 수치. 실제 효과 아님(본문에 표시함) | 수치를 유지할지, 빼고 서술만 남길지 결정 |

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | 1장에서 "하네스"를 정의하는 분량 | 지금처럼 표 한 줄과 예 하나로 유지하고 자세한 내용은 CH10~CH12와 선택 과정(AW-OP03)에서 다룸 |
| 2 | 세 정의를 "작업 정의"로 표시하는 방식 | 공개 문헌 검토 전까지 유지 |
| 3 | 가상 사례 수치 | 제거를 권고(검증되지 않은 수치가 효과처럼 읽힐 수 있음). 저자가 보기에 필요하면 유지 |
| 4 | 이 장에 하네스 사례를 넣을지 | 넣지 않음(현재). 개념 구분 장이라 사례가 부담이 될 수 있음 |
| 5 | 실습 1단계의 "8개 이상" 기준 | 학습자 시험 후 조정. 지금은 유지 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간 30분**(읽기 약 10~15분 + 실습 15~20분). 저자의 예상이며 어떤 학습자에게도 시험하지 않았습니다.
- 미검증: 비개발자가 용어 설명만으로 2-4절을 이해하는지 / 8개 업무를 실제로 적을 수 있는지 / 후보 3가지를 입력·결과물 한 줄로 쓸 수 있는지 / 진단 5문항이 "먼저 손볼 곳"을 실제로 짚어 주는지 / 실습이 학습목표 달성에 도움이 되는지(학습 효과).

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "이미 ChatGPT를 쓰는데 왜 워크스페이스가 필요한가요?" | 도구가 아니라 *자료와 규칙의 정리*가 반복 사용을 가능하게 한다는 2-1절의 책상 비유로 답한다. 도구를 바꾸라는 뜻이 아님을 분명히 한다 |
| "하네스가 뭔가요? 꼭 알아야 하나요?" | 이 책에서는 이름과 구분만 소개하고 후반에 다룬다. 지금은 "규칙대로 했는지 확인하는 장치가 붙은 것" 정도로만 답한다 |
| "업무가 8개 떠오르지 않아요" | 일정표와 메신저의 *제목만* 보도록 안내(7절). 5분짜리 일도 적게 한다 |
| "후보가 너무 커요(예: 보고서 전체)" | 한 단계만 떼어 쓰게 한다(요약 문단 초안 등) |
| "회사가 AI 사용을 금지했어요" | 이 장은 후보를 *적는 것*까지만이므로 가능하다고 안내하되, 실제 사용은 조직 규정이 우선임을 말한다 |
| "AI가 틀리면 누구 책임이죠?" | 이 책의 입장은 "초안은 AI, 확인과 결정은 사람"(저자 해석). 법적 책임 문제는 이 책이 다루지 않으며 조직·법무에 문의하도록 안내 |
| "후보 업무에 민감한 자료가 들어가요" | 지금은 후보만 정한다. 어떤 자료를 넣을 수 있는지는 CH03에서 정한다 |
