# CH05 저자 검토 자료 — 클라우드 저장소와 업무자료 연결

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH05.md`
작성자 자체 검토 반영(2026-10-26, Phase 3B). 저자 승인 전이며 학습자 시험은 하지 않았습니다.

> **필수 실습은 계정 없이 가상 시나리오로 가능합니다. 실제 계정을 쓰는 실습 4는 선택이며 조직 규정을 확인한 뒤 가상 파일만 올립니다.** 이 장은 동기화가 백업을 보장한다고 설명하지 않습니다.

## 1. 장별 핵심 주장

1. 로컬 저장소와 클라우드 저장소는 위치, 인터넷 필요 여부, 공유 방식이 다르다. (일반 설명)
2. 동기화와 백업은 다르다. 동기화는 수정과 삭제가 양쪽에 반영될 수 있으므로 백업이 아니다. (공식 문서 일부 + 저자 해석)
3. Google Drive for desktop은 수정이 컴퓨터와 Drive에 자동 동기화되고, 스트리밍·미러링 방식이 있다. (공식 문서 S11)
4. Google Drive 공유에서 편집·댓글·열기만 가능을 정할 수 있고, 특정인·공개 공유가 있다. (공식 문서 S12)
5. OneDrive 삭제 파일은 개인 30일, 직장·학교 93일 안에 복원 가능(관리자 변경 제외), 영구 삭제 후에는 불가. (공식 문서 S13)
6. 공유 원칙(최소 권한, 링크 공유는 마지막 수단, C 등급 비공유, 기록, 종료 시 중단). (저자 제안)
7. 충돌 사본의 이름 형식은 서비스마다 다르며 이 책은 확인하지 않았다.

## 2. 교육목표

- 로컬·클라우드 차이, 동기화와 백업의 차이.
- Google Drive·OneDrive 기본 사용 방식과 폴더 연결.
- 공유 권한 점검, 충돌·사본, 공유 중단과 복구.
- 후보 A의 클라우드 폴더 구조, 공유·권한 점검표, 동기화 확인표, 저장·공유 규칙.

## 3. 실습과 완료 기준

| 실습 | 구분 | 하는 일 | 완료 기준 |
|---|---|---|---|
| 1 | 필수 | 클라우드 업무 폴더 구조(올릴/안 올릴 폴더) | 모든 폴더에 결정과 이유, C는 기본 제외 |
| 2 | 필수 | 공유 및 권한 점검표 | 권한, 링크 범위, 중단 방법 |
| 3 | 필수 | 동기화 확인표(가상 시나리오 5개) | 5개 답변, 백업 여부와 이유 |
| 4 | 선택 | 실제 계정에 가상 파일로 동기화 확인 | 가상 파일만, 조직 규정 확인 |
| 5 | 필수 | 후보 A 저장·공유 규칙 한 장 | 백업(따로 두는 곳) 포함 |

산출물: 클라우드 업무 폴더 구조, 공유 및 권한 점검표, 동기화 확인표(+ 저장·공유 규칙). 계정이 없거나 조직 정책상 쓸 수 없으면 필수 실습으로 모두 완성됩니다.

## 4. 출처가 필요한 주장

| 본문의 주장 | 출처 | 상태 |
|---|---|---|
| Drive for desktop에서 수정이 양쪽에 자동 동기화 | S11 | 원문 확인 |
| 파일 탐색기에서 Drive 폴더를 일반 폴더처럼 열 수 있음 | S11 | 원문 확인 |
| 스트리밍은 공간을 거의 쓰지 않고 미러링은 전체 복사본을 내려받음 | S11 | 원문 확인 |
| 폴더 추가, 일시 중지·재개, 스트리밍 계정 연결 해제 시 오프라인 파일 제거 | S11 | 원문 확인 |
| 공유 시 편집·댓글·열기만 가능을 정할 수 있고 특정인·공개 공유 가능, 공유 중지는 별도 도움말 | S12 | 원문 확인(페이지에서 접힌 목차 수준까지 읽음. 단계별 절차는 읽지 않음) |
| OneDrive 삭제 복원 기간 30일/93일, 영구 삭제 후 불가, 공유받은 파일 불가 | S13 | 원문 확인 |

**한계:** OneDrive 설치·폴더 동기화 설정, Google Drive의 삭제·버전 복원 방법, 충돌 사본 이름, 요금제별 저장 공간, 조직 계정 관리자 설정은 읽지 않았고 본문에도 "확인하지 않음"으로 적었습니다. S11~S13에는 정확한 갱신 날짜가 표시되지 않았습니다. **수업 직전에 다시 읽어야 합니다.**

**저자 해석:** 동기화≠백업 판단, 공유 원칙, 줄이는 방법, 실습 3 해설.

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | OneDrive 설치·동기화를 공식 문서로 추가 확인해 본문에 넣을지 | 수업 대상이 Microsoft 365 사용자가 많으면 추가 확인 권고 |
| 2 | "동기화가 백업이 아니다" 판단의 강도 | 현재 "삭제·수정이 반영될 수 있다"까지만 씀. 공식 문서가 직접 "백업이 아니다"라고 쓴 것은 확인하지 않았음 |
| 3 | 실습 4(실제 계정) 선택 유지 | 유지. 조직 정책상 불가한 경우가 많음 |
| 4 | 다른 서비스(Dropbox, 네이버 MYBOX 등)를 다룰지 | 이 책은 두 서비스만 다룸. 확장은 저자 결정 |
| 5 | 파일 공유 실습을 실제로 하게 할지 | 현재는 설계만. 실제 공유는 위험이 있어 권하지 않음 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간** 필수 50분, 선택 30분. 저자의 예상이며 시험하지 않았습니다.
- 미검증: 학습자가 동기화와 백업의 차이를 이해하는지 / 가상 시나리오 표가 이해에 도움이 되는지 / 서비스 화면이 본문과 같은지 / 선택 실습의 실제 동작(충돌 사본 등)은 이 책이 직접 해 보지 않았음.

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "OneDrive에 올려 두면 백업 아닌가요?" | 삭제·수정이 반영될 수 있고 복원에는 기간과 조건이 있다(S13). 따로 둔 복사본을 두고 복원을 확인하자고 안내 |
| "회사 계정이 막혀 있어요" | 관리자에게 묻고, 선택 실습은 건너뛰고 시나리오 실습으로 대체 |
| "링크로 공유하면 편한데요" | 최소 권한 원칙, 기간 설정, C 등급 금지. 서비스별 화면 확인 |
| "충돌 사본이 생겼어요" | 내용을 비교해 하나만 남기고 `v` 번호로 정리 |
| "Google Drive 복원 방법은요?" | 이 책이 확인하지 않았으므로 서비스의 공식 도움말을 보게 안내 |
