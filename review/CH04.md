# CH04 저자 검토 자료 — PC·파일·폴더 관리

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH04.md`
작성자 자체 검토 반영(2026-10-26, Phase 3B). 저자 승인 전이며 학습자 시험은 하지 않았습니다.

## 1. 장별 핵심 주장

1. 파일, 폴더, 확장자, 경로를 알아야 AI에 줄 자료를 정확히 고를 수 있다. (일반 설명)
2. 확장자를 보이게 켜 두면 형식을 구분하고 이름 변경 실수를 줄일 수 있다. (일반 설명)
3. 폴더는 업무 기준으로 나누고 깊이 3단계 안팎, 번호 접두어, 업무마다 같은 구조로 만든다. (저자 제안)
4. 파일명 규칙: `[날짜]_[업무]_[내용]_[버전]`, AI 초안은 `_AI초안`으로 구분. (저자 제안)
5. 원본은 손대지 않고 복사해 작업하며, AI 결과는 사람이 확인한 것만 최종본으로 보낸다. (저자 제안)
6. `09_AI에넣지않는자료(C)` 폴더는 실수 방지용 표시이며 보안 통제가 아니다. (저자 해석, 본문에 명시)
7. 이 장은 공식 문서를 인용하지 않는다. Windows 화면 설명은 일반 설명이다.

## 2. 교육목표

- 파일·폴더·확장자·경로 설명, 확장자 표시 켜기.
- TXT, Markdown, Word, PDF, Excel(CSV) 구분.
- 후보 A 업무 폴더, 파일명 규칙, 원본·작업본·최종본 구분.
- 검색과 백업의 기초.
- 후보 A 업무자료 목록(CH03 등급 연결).

## 3. 실습과 완료 기준

| 실습 | 하는 일 | 완료 기준 |
|---|---|---|
| 1 | `연습_가상` 폴더와 가상 파일 8개 만들기 | 가상 파일 8개 |
| 2 | 확장자 표시, 형식 확인표 | 8개 형식 기록 |
| 3 | 표준 업무 폴더 구조 만들기(새 폴더만 추가) | 후보 A 폴더 아래 01~05 존재 |
| 4 | 파일명 규칙 한 장, 가상 파일 3개 이상 이름 바꾸기 | 규칙과 적용 예 |
| 5 | 원본 → 작업본 → 최종본 복사·이동(가상 파일) | 원본 그대로, 폴더 구분 |
| 6 | 후보 A 업무자료 목록(이름·종류만) | 형식, 폴더, 등급, 넣기 전에 할 일 |
| 7(선택) | 검색 연습, 백업 위치 한 줄 | 한 줄 |

산출물 3개: 개인 표준 업무 폴더, 파일명 규칙, 후보 A 업무자료 목록. 실제 파일의 이동·삭제·이름 변경은 하지 않습니다.

## 4. 출처가 필요한 주장

공식 문서 인용 없음. 아래는 일반 설명 또는 저자 해석이며 확인하지 않았습니다.

| 주장 | 비고 |
|---|---|
| `Windows 키 + E`, `F2`, `Ctrl+C/V`, 확장자 표시 메뉴 위치 | 일반 설명. **이 책이 Windows 공식 문서로 확인하지 않았고 Windows 10/11 화면 차이가 있을 수 있음**(본문에 "버전에 따라 다를 수 있음" 표시) |
| Windows 파일 이름에 쓸 수 없는 문자 `\ / : * ? " < > |` | 일반 설명. 공식 문서 미확인 |
| 경로가 길면 문제가 생길 수 있다 | 일반 설명. 구체적 길이 제한은 쓰지 않음 |
| 백업은 서로 다른 장소에 두 벌 이상 | 일반 설명 |
| 폴더 구조, 파일명 규칙, 원본·작업본·최종본 | 저자 제안 |

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | 폴더 번호 체계(00, 10, 20, 90)와 `09_AI에넣지않는자료(C)` | 유지. 단 보안 통제가 아님을 본문에 적었음 |
| 2 | 파일명 규칙의 `_AI초안` 표시 | 유지 |
| 3 | Windows 단축키·메뉴 설명을 공식 문서로 확인할지 | 수업 전 강사가 실제 Windows 화면으로 확인 권고 |
| 4 | 실습 1의 가상 파일 8개를 학습자가 직접 만드는 방식이 번거로운지 | 시험 후 조정. 배포용 압축 파일은 이 책이 아직 만들지 않았음(다운로드 기능 없음) |
| 5 | Markdown을 비개발자에게 소개하는 범위 | 이름과 용도만 소개. 필요하면 CH10에서 확장 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간 60분.** 저자의 예상이며 시험하지 않았습니다.
- 미검증: 학습자가 폴더 구조를 이해하는지 / 확장자 표시 방법이 학습자 화면과 같은지 / 가상 파일 만들기가 번거롭지 않은지 / 자료 목록 작성이 CH03 등급과 매끄럽게 이어지는지 / 폴더 구조가 실제 업무에 맞는지.

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "내 파일 정리를 같이 해도 되나요?" | 이 장은 새 폴더 추가만 한다. 기존 파일 정리는 백업을 확인한 뒤 따로 하도록 안내 |
| "확장자가 안 보여요" | 2-2절. 화면은 Windows 버전별로 다를 수 있음 |
| "폴더를 꼭 이렇게 만들어야 하나요?" | 예시이며 원칙(업무 기준, 같은 구조, 원본 구분)만 지키면 된다 |
| "회사 PC라 폴더를 못 만들어요" | 규정 확인 후 허용된 위치에서 하거나 `연습_가상` 안에서만 실습 |
| "CH01~CH03을 안 했어요" | 첫머리의 가상 예시로 진행 |
