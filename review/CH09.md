# CH09 저자 검토 자료 — 문서작성과 자료분석 실습

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH09.md`
작성자 자체 검토 반영(2026-10-26, Phase 3C). 저자 승인 전이며 학습자 시험은 하지 않았습니다.

> 필수 실습은 AI 서비스 없이 가능합니다. 본문의 *가상 AI 초안*은 실제 AI의 출력이 아니라 **학습용으로 작성자가 일부러 틀리게 쓴 것**이며 본문에도 그렇게 표시했습니다. 이 장은 공식 문서를 인용하지 않습니다.

## 1. 장별 핵심 주장

1. 업무 요청은 목적, 입력자료, 할 일, 결과물 형식, 규칙, 확인 방법의 여섯 부분으로 쓸 수 있다. (저자 설계)
2. 문장은 사실, 추론, 가정, 미확인 정보로 구분하고 최종 결과물에는 사실만 쓴다. (저자 해석)
3. 숫자는 사람이 원자료로 다시 계산하고, 인용은 원문 검색으로 확인한다. (일반 설명 + 저자 제안)
4. AI는 지어냄, 왜곡, 누락, 계산 오류 등을 낼 수 있다고 가정하고 확인한다. 이 책은 AI가 틀리지 않는다고 말하지 않는다. (일반 설명)
5. "계산 식을 같이 보여 달라고 요청하면 오류가 줄어든다"는 효과는 확인하지 않았다. (본문에 명시)
6. AI가 썼더라도 내용의 책임은 승인한 사람에게 있다. (이 책의 입장, 법적 판단 아님)

## 2. 교육목표

요청문 구조, 입력자료·결과물 정의, 초안 작성, 표의 기초 분석, 사실·추론·가정·미확인 구분, 수치·인용 검증, 오류 식별, 사람의 최종 승인.

## 3. 실습과 완료 기준

| 실습 | 하는 일 | 완료 기준 |
|---|---|---|
| 1 | 업무 요청문(여섯 부분) | 여섯 부분 + K01·등급 확인 |
| 2 | 초안 얻기(AI 또는 가상 초안 대체) | `_AI초안` 저장 |
| 3 | 사실 확인표 | 모든 문장에 구분·근거·판정 |
| 4 | 수치·인용 검증 | 합계·평균·비율 재계산, 인용 확인 |
| 5 | 수정본과 최종 승인 기록 | 승인 기록, `03_최종` |

산출물 4개: 업무 요청문, AI 생성 초안(또는 대체 가상 초안), 사실 확인표, 수정된 최종 업무 결과물.

**가상 자료의 정답(검증함):** 7~9월 수량 1,200 + 1,350 + 1,100 = 3,650, 평균 약 1,217, 인하율 700 ÷ 12,500 = 5.6%. 가상 초안은 3,750, 1,250, 5.8%로 일부러 틀리게 썼습니다. 가상 초안의 틀린 곳 6개와 해설은 본문 6절에 있습니다.

## 4. 출처가 필요한 주장

공식 문서 인용 없음. 모두 일반 설명 또는 저자 해석입니다.

| 주장 | 비고 |
|---|---|
| 여섯 부분 구조, 네 구분, 오류 유형 일곱 가지, 승인 절차 | 저자 설계. 외부 기준 아님 |
| AI가 원문에 없는 내용을 만들거나 계산을 틀릴 수 있다 | 일반 설명. 특정 제품의 오류율 등은 말하지 않음 |
| 추론·가정·미확인 용어 정의 | 이 책에서의 쓰임 |

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | 일부러 틀린 가상 AI 초안을 교재에 두는 것 | 검증 연습에 유용. 실제 AI 출력이 아님을 표시함 |
| 2 | 사실 확인표의 구분 4종이 비개발자에게 과한지 | 시험 후 조정 |
| 3 | 후보 A가 회의록 정리가 아닌 학습자의 대체 경로 | "회의 메모를 내 입력자료로 바꿔 읽기"만 안내함. 다른 업무용 예시를 더 줄지 저자 결정 |
| 4 | 수치 검증을 기초 사칙연산에 한정한 것 | 유지 |
| 5 | "책임은 승인한 사람" 문장 | 이 책의 입장으로만 표시. 법무 검토는 받지 않았음 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간 70분.** 저자의 예상이며 시험하지 않았습니다.
- 미검증: 학습자가 사실 확인표를 끝까지 채울 수 있는지 / 가상 초안만으로 실제 AI 오류를 알아보는 능력이 느는지 / 실제 AI가 같은 유형의 오류를 내는지 / 요청문 구조가 결과를 개선하는지.

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "AI가 만든 걸 그대로 쓰면 안 되나요?" | 이 책은 사람이 확인한 것만 최종으로 둔다. 사실 확인표를 보여 준다 |
| "AI 서비스가 없어요" | 가상 AI 초안으로 모든 실습 가능 |
| "계산도 AI가 하면 되잖아요" | 식을 보이게 하되 숫자는 사람이 다시 계산 |
| "추론과 가정이 뭐가 달라요?" | 추론은 사실에서 이끌어 낸 판단, 가정은 확인 없이 놓은 전제. 본문 예 |
| "회사 회의 메모로 해 봐도 되나요?" | 이 장은 가상 자료만. 실제는 CH03과 조직 규정 |
