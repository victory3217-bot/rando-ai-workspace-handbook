# CH03 저자 검토 자료 — AI에 입력할 수 있는 정보와 정보보안

상태: `Draft` · `last_reviewed`: 없음 · 대상 파일: `ko/chapters/CH03.md`

> 이 장은 가장 쉽게 낡고 가장 신중한 검토가 필요합니다. 법률 자문이나 보안 컨설팅이 아니라는 문구가 본문 맨 앞에 있습니다. **회사의 비공개 자료를 AI 서비스에 입력하라는 지시는 어디에도 없습니다.**

## 1. 장별 핵심 주장

1. 전송(입력이 서비스 회사에 도착), 저장(기록이 남는 기간), 학습(모델 개선에 사용)은 *서로 다른 질문*이다. (일반 설명 + 저자 해석)
2. 업무자료를 A(넣어도 됨) / B(가린 뒤, 조직이 허용한 서비스에서만) / C(넣지 않음)로 나눠 판단할 수 있다. (**저자의 교육용 기준. 법적 분류나 공인 기준이 아님**)
3. ChatGPT와 Claude의 개인용·업무용 제품은 데이터 처리가 다르며, 공식 문서에서 확인한 내용은 출처 S1~S5와 함께 별도 상자에 있다. (공식 문서)
4. 업무용 제품이 기본적으로 학습에 쓰이지 않더라도 *무엇을 넣어도 된다*는 뜻은 아니며 조직 규정이 우선한다. (저자 해석)
5. 비밀번호와 API 키는 *열쇠*이므로 AI 서비스에 입력하지 않는다. (일반적인 보안 권고, 특정 서비스의 공식 지침 아님)
6. 연습은 가상자료로 한다. 가상자료는 이름, 금액, 연락처를 바꾸되 내용 자체가 식별 정보가 되지 않게 한다. (저자 해석)
7. 하네스 사례 한 곳(rando-client-discovery-harness)은 "저장하지 않는 것"과 "전송하지 않는 것"이 다르다고 문서 첫머리에서 밝힌다. (확인한 사실)

## 2. 교육목표

- 전송, 저장, 학습이 다른 질문임을 설명한다.
- 업무자료를 A/B/C로 나누고 이유를 말한다.
- 개인정보, 일반적으로 민감한 정보, 비밀번호, API 키를 AI 서비스에 입력하지 않는 습관을 정한다.
- 내가 쓰는 AI 서비스의 데이터 처리를 공식 문서와 내 설정 화면에서 확인하는 방법을 안다.
- 개인용·조직용 계정의 차이를 알고 업무에 쓸 계정을 담당자에게 묻는다.
- 가상자료로 안전하게 연습한다.

**필수 학습 / 참고 학습 구분(저자의 제안, 본문에 표시함)**
- 필수: 2-1, 2-2, 2-5, 2-6, 실습 1·2
- 참고: 2-3, 2-4, 실습 3·4

## 3. 실습과 완료 기준

| 실습 | 구분 | 하는 일 | 완료 기준 |
|---|---|---|---|
| 1 | 필수 | 가상 파일 12개를 A/B/C로 분류 | 12개 분류, 이유 한 줄 |
| 2 | 필수 | 가상 회의 메모에서 이름·금액·연락처 가리기 | 가린 버전에 이름·금액·연락처 0개 |
| 3 | 참고 | 내가 쓰는 AI 서비스 확인표(설정 화면은 *읽기만*) | 확인표 1개 이상, 모르는 칸은 "모름" |
| 4 | 참고 | 내 업무 파일 *종류별* 등급표(파일 내용은 열지 않음) | 등급표 + "절대 넣지 않는 것" 목록 |

해설표(12개 분류의 저자 기준)와 가린 예시는 본문 6절에 있고, "정답이 아니라 저자의 기준"이라고 표시했습니다.

## 5. 저자의 의사결정이 필요한 항목

| # | 결정할 것 | 작성자의 권고 |
|---|---|---|
| 1 | 정보 등급을 3단계(A/B/C)로 둘지 | 유지. 법적 분류가 아님을 본문 맨 앞과 2-2절에 모두 적었음. 법무 검토가 가능하면 받기를 권고 |
| 2 | B 등급의 "조직이 허용한 서비스·계정에서만" 문구 | 유지(안전 측) |
| 3 | 해설표의 2번(내부 회의록)·3번(거래처 단가표)·10번(투자자 배포 전 사업계획서) 판단 | 판단이 갈리는 항목임. 저자의 경험으로 조정 필요 |
| 4 | 필수/참고 구분 | 저자 제안. 학습 시간 압박이 없으면 구분을 없애도 됨 |
| 5 | 공식 정책을 본문에 길게 넣을지, 링크만 둘지 | 정책이 자주 바뀌므로 분량을 줄이고 링크 중심으로 바꾸는 안도 가능. 현재는 상자로 요약해 두었고 변경 부담은 큼 |
| 6 | 수업 전 공식 문서 재확인 절차를 누가 언제 할지 | 수업 하루 전 S1~S5를 다시 열어 날짜·내용 변경 확인. 바뀌면 본문, 9절 표, `source-map.md` 갱신 |
| 7 | 한국 개인정보 관련 법령을 본문에서 언급할지 | 현재는 언급하지 않고 "법령상 정의는 다를 수 있다"만 적음. 언급하려면 법무 검토 필요 |
| 8 | 실습 3(설정 화면 읽기)을 조직 계정에서 하게 할지 | 조직 계정은 관리자 승인이 필요할 수 있음(본문에 안내). 강사가 사전에 확인 |

## 6. 예상 실습시간과 미검증 사항

- **예상 시간 50분**. 저자의 예상이며 시험하지 않았습니다. 필수 학습만 했을 때의 시간은 측정하지 않았습니다.
- 미검증: 비개발자가 용어 설명(모델 학습, API 키, 비식별화 등)만으로 이해하는지 / 분량(본문 약 300줄)이 한 번에 소화 가능한지 / 12개 분류와 해설표가 학습에 도움이 되는지 / 가린 메모에서 식별 정보가 실제로 모두 사라졌는지 학습자가 스스로 판단 가능한지 / 설정 화면이 본문의 메뉴 이름과 같은지(계정, 요금제, 앱 버전, 지역에 따라 다를 수 있음) / 이 장이 학습자의 실제 행동(민감정보 미입력)을 바꾸는지.

## 7. 강사용 예상 질문과 오류 대응 (초안, 사용해 본 적 없음)

| 예상 질문·상황 | 대응(안) |
|---|---|
| "회사 자료를 ChatGPT나 Claude에 넣어도 되나요?" | 이 책이 정할 수 없고 조직 규정이 우선. 먼저 조직이 허용한 서비스·계정을 확인하고, 허용되어도 정보 등급 B는 가린 뒤, C는 넣지 않는다고 안내 |
| "학습을 껐으니 안전하죠?" | 아니라고 답한다. 전송과 저장은 별개이고, 피드백을 보내면 예외가 있다(S1, S2, S3) |
| "임시 채팅이면 괜찮나요?" | 공식 문서상 임시 채팅은 모델 개선에 쓰이지 않지만 안전 목적으로 최대 30일 보관될 수 있다(S1, S2). 입력 자체는 전송된다 |
| "Claude 시크릿 대화는요?" | 모델 개선에 쓰이지 않는다고 문서에 있다(S3). 보관과 전송에 관한 다른 내용은 이 책에서 확인하지 않았다 |
| "회사 계정이면 다 되는 거죠?" | 업무용 제품의 기본값은 학습 미사용이지만(S1, S2, S5) 어떤 자료를 넣을지는 회사 규정이 정한다 |
| "이미 민감한 내용을 넣었어요" | 7절 순서: 조직 자료면 담당자에게 알림 → 해당 대화 삭제(학습 설정을 끄는 것만으로는 삭제되지 않음, S2) → 비밀번호·API 키였다면 폐기. 삭제해도 이미 진행 중이거나 학습된 모델에 들어간 데이터는 남을 수 있다고 Claude 문서가 밝힌다(S4) |
| "화면이 문서와 달라요" | 요금제, 앱 버전, 지역, 조직 설정에 따라 다를 수 있다. 내 화면을 우선하고, 확실하지 않으면 "모름"으로 적고 담당자에게 묻는다 |
| "이 정도면 개인정보보호법을 지킨 건가요?" | 이 책의 기준은 법적 기준이 아니다. 법령 준수 여부는 조직의 정보보안·법무 담당자에게 확인하도록 안내 |
| "가상자료에 실제 회사 이름을 써도 되나요?" | 쓰지 않는다. 구조는 같고 내용이 가짜인 자료여야 한다(2-6절) |
| "API 키를 이미 붙여 넣었어요" | 노출된 것으로 보고 해당 서비스에서 즉시 폐기하고 새로 만든다. 발급 서비스마다 화면이 다르므로 그 서비스의 안내를 따른다 |
