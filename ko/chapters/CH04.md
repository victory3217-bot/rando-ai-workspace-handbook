## 1. 학습목표

이 장을 마치면 다음을 할 수 있다.

- 파일, 폴더, 확장자, 경로가 무엇인지 설명하고 Windows 파일 탐색기에서 확장자를 보이게 할 수 있다.
- TXT, Markdown, Word, PDF, Excel(CSV) 파일의 차이를 말하고, 업무에 맞는 형식을 고를 수 있다.
- 후보 업무 A를 위한 업무 폴더 구조를 설계해 만들 수 있다.
- 날짜, 업무, 버전이 보이는 파일명 규칙을 정하고 적용할 수 있다.
- 원본, 작업본, 최종본을 구분해 보관하는 이유를 설명할 수 있다.
- 파일을 검색하고, 중요한 파일의 백업을 어디에 둘지 한 줄로 정할 수 있다.
- 후보 A에 필요한 업무자료 목록을 만들고 CH03의 등급과 연결할 수 있다.

## 2. 핵심 개념

**이 장에서 쓰는 말**
- **파일**: 컴퓨터에 저장되는 자료 하나. 문서, 표, 사진 등.
- **폴더**: 파일을 담는 상자. 폴더 안에 폴더를 둘 수 있습니다.
- **확장자**: 파일 이름 끝의 `.docx`, `.pdf` 같은 부분. 파일의 종류를 알려 줍니다.
- **경로**: 파일이 어느 폴더 안에 있는지 적은 주소. 예: `문서\AI업무\10_회의록정리\03_최종`.
- **원본**: 처음 받았거나 처음 만든, 손대지 않는 파일.
- **작업본**: 원본을 복사해 고치는 파일. **최종본**: 확정해서 공유하거나 제출하는 파일.
- **버전**: 같은 파일을 고칠 때마다 구분하는 번호. `v01`, `v02`처럼 씁니다.
- **백업**: 파일이 사라지거나 망가질 때를 대비해 *다른 곳에 따로 두는 복사본*. 같은 파일을 여러 곳에 맞춰 두는 동기화와는 다릅니다(CH05).

### 2-1. 파일, 폴더, 확장자

AI 워크스페이스(CH01)의 바탕은 *내가 내 자료를 어디에 두었는지 아는 것*입니다. AI 서비스에 자료를 줄 때도 파일을 올리거나 붙여 넣는데, 어느 파일인지 모르면 줄 수 없고, 어느 것이 최신인지 모르면 틀린 자료를 주게 됩니다.

확장자는 파일을 *어떤 프로그램으로 열지* 정합니다. 확장자를 바꾼다고 파일 내용이 바뀌지 않으므로, `.docx`를 `.pdf`로 이름만 바꾸면 열리지 않습니다. 파일 이름을 바꿀 때 확장자까지 지우지 않도록 주의합니다.

### 2-2. Windows 파일 탐색기 사용

파일 탐색기는 Windows에서 파일과 폴더를 보는 기본 프로그램입니다. 키보드의 `Windows 키 + E`를 누르거나 작업 표시줄의 폴더 모양 아이콘을 누르면 열립니다. (화면은 Windows 버전에 따라 조금 다를 수 있습니다.)

| 하고 싶은 일 | 방법 |
|---|---|
| 폴더 안으로 들어가기 | 폴더를 두 번 누른다 |
| 위로 올라가기 | 위쪽 화살표 단추를 누르거나 주소창에서 위쪽 폴더 이름을 누른다 |
| 새 폴더 만들기 | 빈 곳에서 오른쪽 단추 → 새로 만들기 → 폴더 |
| 이름 바꾸기 | 파일을 한 번 누르고 `F2` 키를 누른 뒤 이름을 입력한다 |
| 복사하기 | 파일을 선택하고 `Ctrl + C`, 붙여 넣을 폴더에서 `Ctrl + V` |
| 확장자 보이게 하기 | 위쪽 메뉴의 `보기`에서 `표시`(또는 `보기` 탭)를 열어 `파일 확장명`을 켠다 |
| 경로 확인하기 | 위쪽 주소창을 본다 |

**확장자는 꼭 보이게 켜 두세요.** 그래야 `보고서.docx`와 `보고서.pdf`를 구분하고, 이름을 바꾸다 확장자를 지우는 실수를 알아챌 수 있습니다.

### 2-3. 파일 형식 비교

| 형식 | 확장자 | 어떤 파일인가 | 업무에서 쓰는 곳 |
|---|---|---|---|
| TXT | `.txt` | 꾸밈이 없는 글자만 있는 파일. 메모장으로 열림 | 메모, 규칙 메모, 복사해 붙여 넣을 글 |
| Markdown | `.md` | 글자 파일에 `#` 제목, `-` 목록 같은 기호로 구조를 적은 것. 메모장으로도 열림 | AI에게 줄 지침과 양식 |
| Word | `.docx` | 글꼴, 표, 그림 등 편집 서식이 있는 문서 | 보고서, 회의록, 안내문 |
| PDF | `.pdf` | 모양이 고정된 문서. 보통 읽기용 | 제출용, 공유용 최종본 |
| Excel | `.xlsx` | 계산과 표 서식이 있는 표 | 목록, 집계, 계산 |
| CSV | `.csv` | 쉼표로 칸을 나눈 단순한 표. Excel로 열림 | 표 자료를 서식 없이 주고받을 때 |

> **저자 해석** AI에게 줄 *지침과 양식*은 TXT나 Markdown처럼 서식이 없는 파일이 다루기 쉽고, *결과물과 제출본*은 Word나 PDF가 편합니다. 다만 AI 서비스마다 읽을 수 있는 파일 형식과 한도가 다르므로, 어떤 형식이 되는지는 CH06(ChatGPT)과 CH07(Claude)에서 각 서비스의 공식 문서로 확인합니다. 이 장은 특정 서비스의 지원 여부를 말하지 않습니다.

### 2-4. 업무 폴더 구조 설계

**원칙(저자의 제안):** ① 폴더를 *업무 기준*으로 나눕니다. ② 깊이는 세 단계 안팎으로 둡니다. ③ 이름 앞에 번호를 붙여 순서를 고정합니다. ④ 같은 종류의 폴더는 업무마다 같은 구조로 만듭니다.

후보 A를 위한 표준 구조의 예입니다.

```text
AI업무/
  00_안내/                      ← 이 구조의 사용 규칙, 파일명 규칙
  10_업무A_회의록정리/
    01_원본/                    ← 받은 그대로, 손대지 않음
    02_작업중/                  ← 원본을 복사해 고치는 곳
    03_최종/                    ← 확정해 공유하는 파일
    04_AI지침과양식/            ← CH02의 ④·⑤ 칸에 해당
    05_AI결과와검증기록/        ← AI 초안과 확인한 기록
    09_AI에넣지않는자료(C)/     ← CH03에서 C로 본 자료
  20_업무B_/                    ← 후보 B, 같은 구조로 만든다
  90_보관/                      ← 끝난 일
```

CH02의 다섯 칸과의 관계: `01_원본`~`03_최종`은 ①(PC·로컬 파일)의 *업무 파일*, `04_AI지침과양식`은 ④(업무문서)와 ⑤(지침서)의 *시작 자리*입니다. 이 자리는 CH08(지식베이스)과 CH10(지침서)에서 채워집니다.

> **저자 해석** `09_AI에넣지않는자료(C)` 폴더는 *내가 실수로 올리지 않도록 눈에 보이게 구분하는 장치*일 뿐이며 보안 통제가 아닙니다. 폴더에 넣었다고 AI에 올라가지 않는다는 보장은 없고, C 등급 자료의 실제 처리는 조직 규정이 우선합니다(CH03).

### 2-5. 파일명 규칙과 버전 구분

**규칙의 예(저자의 제안):**

```text
[날짜]_[업무]_[내용]_[버전].확장자
2026-10-12_영업회의록_3분기_v01.docx
```

- 날짜는 `연-월-일` 순서로 맨 앞에 씁니다. 이름순으로 정렬하면 날짜순이 됩니다.
- 버전은 `v01`, `v02`로 올립니다. 최종본은 파일 이름에 `최종`을 쓰는 대신 `03_최종` 폴더에 두거나 `_확정`을 붙입니다.
- AI가 만든 초안은 `_AI초안`을 붙여 사람이 만든 파일과 구분합니다.
- `\ / : * ? " < > |` 문자는 Windows 파일 이름에 쓸 수 없습니다. 그 밖에 띄어쓰기와 특수문자가 많으면 다른 프로그램에서 문제가 생길 수 있어 `_`로 연결하는 것을 권합니다.

피할 이름: `회의록최종.docx`, `회의록최종_진짜최종(1).docx`, `새 문서.docx`. 어느 것이 마지막인지, 무슨 내용인지 알 수 없습니다.

### 2-6. 원본, 작업본, 최종본

```text
01_원본 (받은 그대로)  →  복사  →  02_작업중 (고치는 파일, v01, v02...)  →  확정  →  03_최종 (공유하는 파일)
```

- 원본은 고치지 않습니다. 잘못 고쳤을 때 돌아갈 곳이 됩니다.
- AI에게는 가능하면 *원본이 아니라 사본이나 가려 놓은 파일*을 줍니다(CH03).
- AI가 만든 결과(`_AI초안`)는 `05_AI결과와검증기록`에 두고, 사람이 확인해 고친 것만 `02_작업중`을 거쳐 `03_최종`으로 보냅니다.

### 2-7. 파일 검색과 백업의 기초

**검색:** 파일 탐색기 오른쪽 위 검색 칸에 이름 일부를 입력하면 현재 폴더 안에서 찾습니다. 파일명 규칙이 있으면 `영업회의록`이나 `2026-10`만 입력해도 찾을 수 있습니다. 확장자로 찾으려면 `*.docx`처럼 입력합니다. 폴더 안이 아니라 컴퓨터 전체에서 찾는 방법과 필터 화면은 Windows 버전에 따라 다릅니다.

**백업의 기초(일반 설명):** 중요한 파일은 *서로 다른 장소에 두 벌 이상* 보관하는 것이 기본입니다. 같은 컴퓨터의 다른 폴더는 컴퓨터가 고장 나면 함께 잃기 쉽습니다. 백업은 **한 번 복원해 보기 전에는 되는지 알 수 없습니다.** 클라우드와 동기화는 CH05, 백업과 버전 관리의 더 자세한 방법은 CH13에서 다룹니다.

## 3. 업무 적용 사례

가상의 회사 '예시상사'의 한가상 씨는 회의록 정리(후보 A)를 위해 파일을 모으다 아래 상태를 발견했습니다. (모두 가상)

| 모습 | 문제 |
|---|---|
| 바탕화면에 `회의록최종.docx`, `회의록최종_진짜최종(1).docx`, `새 문서.docx`가 흩어져 있다 | 어느 것이 마지막인지 모르고, AI에게 줄 때 틀린 파일을 줄 수 있다 |
| 받은 메모 원본에 바로 고쳐 썼다 | 원래 내용으로 돌아갈 수 없다 |
| 고객 안내문 양식과 회의 메모가 한 폴더에 섞여 있다 | 가려 놓은 파일과 아닌 파일을 구분하기 어렵다 |

한가상 씨는 2-4절의 구조를 만들고, 파일 이름에 날짜와 버전을 붙이고, 원본은 `01_원본`에 두고 사본으로 작업하기로 정했습니다. 효과(시간이 얼마나 줄었는지 등)는 이 책이 확인한 것이 아니라 가상의 예상입니다. 이 장에는 하네스 사례를 쓰지 않았습니다.

- 선수학습: CH01(후보 A와 목적), CH02(구성도), CH03(자료 검토표). 없으면 이 장 첫머리의 가상 예시를 씁니다.

- **시작 상태:** CH01의 후보 A와 목적, CH02의 ① 칸, CH03의 자료 검토표가 있다(없으면 가상 예시).

### 실습 1. 연습 폴더와 가상 파일 만들기

내 문서 폴더 안에 `연습_가상`이라는 새 폴더를 만들고, 그 안에 빈 파일 8개를 만드세요. 새 폴더에서 오른쪽 단추 → 새로 만들기 → 텍스트 문서로 만든 뒤 이름을 바꿔 확장자를 `.docx`, `.xlsx` 등으로 바꿔도 되고, 이름만 같은 연습용 파일이면 됩니다(내용은 비어 있어도 됩니다). **이 파일들은 모두 가상입니다.**

```text
회의록최종.docx
회의록최종_진짜최종(1).docx
새 문서.docx
영업회의_메모_받은것.txt
```

### 실습 3. 표준 업무 폴더 구조 만들기

`연습_가상` 안에 2-4절의 구조를 먼저 만들어 봅니다. 구조가 마음에 들면 내 실제 문서 폴더 아래에 같은 구조의 `AI업무` 폴더를 **새로 만듭니다.** 이때 *새 폴더를 추가*하는 것만 하고, 기존 파일을 옮기거나 지우지 않습니다. 조직 컴퓨터라면 폴더를 만들 위치에 규정이 있는지 먼저 확인합니다.

```text
[1] 내 표준 업무 폴더 (CH02의 ① 칸과 연결)

```

## 7. 오류 해결

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 파일 이름 끝의 `.docx`가 보이지 않는다 | 확장자 표시가 꺼져 있다 | 2-2절의 방법으로 `파일 확장명`을 켠다 |
| 이름을 바꿨더니 파일이 열리지 않는다 | 확장자를 지웠거나 바꿨다 | 이름 끝에 원래 확장자를 다시 붙인다. 원래 확장자는 그 파일을 만든 프로그램의 형식이다 |
| 이름을 바꿀 수 없다고 나온다 | 그 파일이 다른 프로그램에서 열려 있다 | 프로그램을 닫고 다시 시도한다 |
| 파일을 어디에 저장했는지 모르겠다 | 저장 위치를 보지 않고 저장했다 | 검색 칸에 이름 일부를 입력한다. 앞으로는 저장할 때 폴더를 직접 고른다 |
| 폴더 이름이 너무 길어 복사가 안 된다 | 경로가 너무 길면 일부 프로그램에서 문제가 생길 수 있다 | 폴더 이름을 줄이고 깊이를 줄인다 |
| 연습 파일을 실수로 지웠다 | 삭제 | 휴지통에서 복원한다. 휴지통을 비웠다면 가상 파일이므로 다시 만든다. **실제 파일은 이 장에서 지우지 않습니다** |
| 후보 A 자료가 모두 C 등급이다 | 후보 A가 민감한 자료에 의존한다 | CH03의 안내대로 가상자료로 바꾸거나 CH01로 돌아가 다른 후보를 고른다 |
