## 1. Learning Objectives

When you finish this chapter, you will be able to do the following.

- Write the basic structure of an AI work request (purpose, input material, task, output format, rules, how to check).
- Define the input material and the expected output.
- Divide the sentences in an AI-made draft into *fact, inference, assumption, and unconfirmed information*.
- Recalculate the totals, averages, and ratios in a table from the original data, and check whether a quotation really appears in the source text.
- Find fabrication, distortion, omission, and calculation errors in AI output.
- Apply a procedure in which a person gives final approval to the corrected output.

## 2. Core Concepts

**Terms used in this chapter**
- **Work request**: Writing that hands a task to AI. It is a kind of prompt; in this book it means one that has a defined structure.
- **Fact**: Content written exactly as it is in the source text (notes, material), so you can verify it.
- **Inference**: A judgment drawn from facts. It sounds plausible but is not written in the source text.
- **Assumption**: A premise taken as true without checking.
- **Unconfirmed information**: Information that you cannot yet tell is true.
- **Hallucination (fabrication)**: When AI makes up content that is not in the source text and presents it as fact. This book also calls it "fabrication."
- **Quotation**: Copying words or numbers from the source text exactly as they are.

### 2-1. Basic structure of an AI work request

If a request is vague, the result is vague. If you include the six parts below, it is easy to carry over into the work instructions in CH10.

| Part | What you write | Example (candidate A) |
|---|---|---|
| ① Purpose | Why you are doing this task | Create a draft of the meeting minutes to reduce the organizing burden |
| ② Input material | What you give, and its tier | Masked fictional meeting notes (B) |
| ③ Task | The work to be done | Organize decisions, owners, deadlines, and open items in a table |
| ④ Output format | Shape, items, length | Table + "Needs confirmation" list, within one page |
| ⑤ Rules | What not to do, what to do when you don't know | Do not write anything that is not in the notes; mark it "Needs confirmation" |
| ⑥ How to check | What the person will check | Whether decisions, owners, and deadlines match the notes |

### 2-2. Defining input material and expected output

- **Input material:** Did you check the tier from CH03? Which version is it (CH04 file-naming rules)? What does it contain, and what is missing?
- **Expected output:** Who will use it? Which items are required? What will you not do (making decisions on someone's behalf, sending it outside, and so on)? *Writing down first the conditions under which you can say the output is finished* makes verification easier.

### 2-3. Drafting with AI

1. Write the request (section 2-1). 2. Run it in a Project (CH06, CH07) or in a chat. 3. Save the output as a *draft* (`_AI_draft`, CH04). 4. Ask for a list of the parts that need checking. Do not expect a finished version in one try; tell the AI which parts are wrong and have it rewrite them, or correct them yourself.

### 2-4. Basic analysis of documents and tables

When you read a table, first look at *what the rows are, what the columns are, and what the unit is*. Four kinds of basic analysis are enough.

| What you want to do | Method | Example |
|---|---|---|
| Total | Add all the values | 1,200 + 1,350 + 1,100 = 3,650 |
| Average | Total ÷ count | 3,650 ÷ 3 ≈ 1,217 |
| Change or ratio | Difference ÷ starting value | (12,500 − 11,800) ÷ 12,500 = 0.056 → 5.6% |
| Count | Count the items that meet a condition | Number of decisions with no owner |

> **Author's interpretation** When you ask AI to do an analysis, ask it to *write out the calculation process too* ("Show the formula: which values did you add for the total?"). And **a person recalculates the numbers with a calculator.** AI can get a calculation wrong. This book has not tested whether this way of asking reduces errors.

### 2-5. Separating fact, inference, assumption, and unconfirmed information

| Category | Example (based on the fictional notes) | How to handle it |
|---|---|---|
| Fact | "Manager A opposed the cut" (it is in the notes) | Write it as is |
| Inference | "The price cut seems to have been a burden" (not in the notes) | Mark it as an inference or do not write it |
| Assumption | "Associate B will send it by next Tuesday" (the notes say "by next week") | Mark it as an assumption and check it |
| Unconfirmed | "Date of the next meeting" (the notes say undecided) | Leave it as "Needs confirmation" |

**Rule:** In the final output, write *only facts*, mark inferences and assumptions so they stand out, and do not leave unconfirmed items blank; write "Needs confirmation." To make AI keep this separation, write it in rule ⑤ of the request.

### 2-6. Verifying numbers and quotations

- **Numbers:** Compare them with the numbers in the source text character by character → recalculate totals, averages, and ratios yourself → check the unit (KRW, units, %).
- **Quotations:** For words in quotation marks, search (`Ctrl + F`) to check that they appear in the source text *exactly*. If they do not, it is not a quotation; it is words that were made up.
- **Sources:** If AI writes "according to ...", check that the source is actually inside the input material. Do not trust a source that is not in the input material.

### 2-7. Identifying errors in AI output

| Error type | What it looks like | How to find it |
|---|---|---|
| Fabrication | A decision, quotation, or number that is not in the notes | Look up every sentence in the source text |
| Distortion | The meaning changes (a "revised proposal" becomes a "price-cut proposal") | Compare key words with the source text |
| Omission | An item that was there is missing (open items) | Compare the number of items in the source with the number in the result |
| Calculation error | The total, average, or ratio is wrong | Recalculate it yourself |
| Format error | Not the table format you asked for | Compare with request part ④ |
| Overconfidence | States something as certain that is not known | Check where a "Needs confirmation" mark should be |
| Source confusion | Cites a source that is not in the input | Check that the source is in the input material |

### 2-8. The procedure for human final approval

1. Fill in the fact-check table to the end. 2. Make a corrected version that fixes the wrong parts. 3. The approver writes down *the items checked and the date*. 4. Send only the approved file to `03_Final` and share it. Even if AI wrote it, **the person who approved it is responsible for the content** (this book's position, Author's interpretation). For questions of legal responsibility, ask your organization or legal staff.

## 6. Verify the Result

You are done when all of the following are true.

1. The work request has all six parts, and it states the K01 rules and the CH03 tier check.
2. Every sentence in the fact-check table has a category, a basis in the source, and a verdict.
3. Every item in the number and quotation verification table was calculated yourself or looked up in the source text, and given a verdict.
4. The corrected version has nothing that is not in the notes, and unconfirmed items are left as "Needs confirmation."
5. The approval record has the items checked, the remaining "Needs confirmation" items, and the approver and date.
6. You did not enter real meeting content, personal information, or customer material anywhere.

## 7. Troubleshooting

| Symptom | Cause | How to fix it |
|---|---|---|
| AI writes content that is not in the notes | The rules in the request are weak, or the input material is vague | Add "Do not write anything that is not in the notes" to request part ⑤ and have a person check. This book does not say AI never makes mistakes |
| The result is different every time | AI's responses can differ even for the same request | Make the request more specific, and save a result you like as a file to use as a reference |
| The calculation keeps coming out wrong | AI can get a calculation wrong | Do the calculation yourself with a calculator, and ask the AI to show the formula |
| I can't tell how much is fact | There are no source marks | For each sentence, write which line of the notes it comes from. If you cannot find it, do not write it as fact |
| It says it's wrong even though I copied the source exactly | The source text itself may be wrong | Check with the person in charge whether the source text itself is correct |
| There is no one to check | No approver has been designated | Ask who your organization's approver is. Do not share it until one is designated |
| The draft contains personal information | It was in the input material | Stop using it immediately, tell the person in charge, and delete that chat (CH03 section 7) |
