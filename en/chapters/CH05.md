## 1. Learning Objectives

When you finish this chapter, you will be able to do the following.

- Explain the difference between local storage and cloud storage.
- Explain that sync and backup are different, and why sync alone does not mean you have a backup.
- Describe the basic way Google Drive and OneDrive work, and say how a folder on your PC and a cloud folder are connected.
- Decide and check permissions (view, comment, edit) and the sharing scope when you share a file.
- Recognize situations that cause sync conflicts and extra copies, and know how to stop sharing and how to recover deleted files.
- Create a cloud folder structure, a sharing and permissions checklist, and a sync check table for candidate A.

## 2. Core Concepts

**Terms used in this chapter**
- **Local storage**: Storage space inside your own computer. Files open without the internet.
- **Cloud storage**: A place where files are kept on a service company's servers, such as Google Drive or OneDrive.
- **Sync (synchronization)**: A feature that makes the other side match when you change one side. It *keeps the same file matched in several places*; it is not keeping a separate copy.
- **Backup**: A copy kept *separately* in case of an accident (CH04). The key point is that it does not change along with the original.
- **Access permission**: A setting that decides who can view, comment on, and edit a file.
- **Conflict copy**: A copy that is created separately when the same file is edited in two places at the same time and the two cannot be matched (the name format differs by service).

### 2-1. Local storage and cloud storage

| | Local storage | Cloud storage |
|---|---|---|
| Location | Your computer | The service company's servers |
| Internet | Opens without it | Usually needed (some services have an offline feature) |
| From another device | Cannot be opened | Can be opened with the same account |
| Sharing | You copy the file and send it | You can share by link or invitation |
| Caution | You can lose it if the computer breaks | You must manage sharing settings and account security yourself |

### 2-2. Sync and backup are different

> **Official documentation check — the nature of sync and recovery of deleted files, checked on 2026-10-26**
>
> - It explains that when you use Google Drive for desktop, edits you make to a file are automatically synced to both your computer and Google Drive. `[S11]`
> - Files that are deleted, overwritten, or damaged in OneDrive *can sometimes be restored.* For a personal account, this is within 30 days after deletion; for a work or school account, within 93 days (if an administrator has not changed it). After you permanently delete a file from the Recycle Bin, it cannot be restored, and a file that someone else shared with you cannot be restored. `[S13]`

> **Author's interpretation** This is a judgment this book draws from the facts above. With sync, where edits are automatically reflected on both sides, a mistaken edit or a deletion can be reflected on both sides too. Even when a restore feature exists, it has time limits and conditions (`[S13]`), so **you should not assume you have a backup just because sync is turned on.** Keep a *separate copy* for important files, as decided in CH04, and check once that restoring works. This book has not confirmed all the detailed conditions on the service side.

| | Sync | Backup |
|---|---|---|
| Purpose | Use the same latest state in several places | Go back after an accident |
| If you delete on one side | It can be deleted on the other side too | The backup copy remains |
| If you edit by mistake | The other side can change too | The earlier state remains |
| In this book | CH05 | CH04 (basics), CH13 (advanced) |

### 2-3. The basics of Google Drive and OneDrive

With both services, you can upload, download, and share files in a *web browser*, and *if you install a program on your PC*, the cloud folder appears in File Explorer like an ordinary folder.

> **Official documentation check — Google Drive for desktop, checked on 2026-10-26**
>
> - When you use Drive for desktop, you can open the Google Drive folders (`My Drive`, `Shared drives`, and so on) in File Explorer like other folders. `[S11]`
> - If you *stream* files, they use almost no space on your computer; if you *mirror* them, a full copy is downloaded to your computer. Space on your computer and Google storage space are not the same thing. `[S11]`
> - You can add more folders to sync, and you can pause syncing and start it again. `[S11]`
> - If you disconnect a streaming account, the offline files are removed from your computer. `[S11]`

This book did not confirm the installation and basic screens of OneDrive in official documentation. In this chapter, only the *recovery of deleted files* for OneDrive (`[S13]`) was confirmed; for installation and folder sync settings, follow the guidance on your own screen and the official OneDrive help. For work or school accounts, whether you can use it and which features are available may differ according to the administrator's policy.

### 2-4. Connecting a local folder and a cloud folder

There are two main ways to put the `AI_Work` folder from CH04 into the cloud.

1. **Put the work folder inside the cloud folder.** Open the cloud folder (for example, the Google Drive folder) and create the `AI_Work` structure inside it. Create it locally by *copying*, check it, and then move it.
2. **Add the existing folder as a folder to sync.** If the program supports it, add your `AI_Work` folder as a folder to sync ("add folders to sync" in `[S11]`).

> **Author's interpretation** Start by testing with *a practice folder or fictional files*, and connect the real work folder after that. Once connected, a copy of the folder also exists in the cloud, so write the cloud in the "where copies remain" column of the CH02 data movement table. By default, do not upload the `09_Do_Not_Give_to_AI_(Tier_C)` folder from CH04 to the cloud; the actual handling follows your organization's rules.

### 2-5. File sharing and access permissions

> **Official documentation check — Google Drive sharing, checked on 2026-10-26**
>
> - When you share a file in Google Drive, you can decide whether people can *edit*, *comment*, or *only view*. `[S12]`
> - You can share files and folders with specific people or share them publicly. `[S12]`
> - How to stop or change sharing and how to transfer ownership are in separate help pages. `[S12]`

> **Author's interpretation** Sharing principles (the author's suggestion): ① Only to the people who need it, and only as much as they need (start in the order view → comment → edit). ② Use "anyone with the link" as a last resort, and if you use it, set a time limit. ③ Do not share Tier C material (CH03). ④ Record that you shared (with whom, when, and which permission). ⑤ Stop sharing when the work is finished. Permission names and screens differ by service, so the explanation on your own screen comes first.

**Connecting to AI services:** When you connect cloud files to an AI service, the range the AI service can read gets wider. How each connection works is confirmed in CH06 (ChatGPT) and CH07 (Claude) using each service's official documentation. This chapter does not turn on any connection.

### 2-6. Sync conflicts and copy problems

If you edit the same file *on two devices at the same time*, or *separately while offline*, a conflict that cannot be matched occurs, and the service may create a conflict copy. The format of the copy's name differs by service, and this book did not confirm the format.

**Ways to reduce it (the author's suggestions):** Only one person edits the same file at a time / Check that syncing has finished before you edit / Save by raising the version number, `v01`, `v02`, in the file-name rule (CH04) / If you see a copy, compare the contents and keep only one.

### 2-7. Stopping sharing and recovery

- **Stopping sharing:** `Remove` the permission or set link sharing back to `Restricted`. The location differs by service, so check your own screen, and after stopping, check that the file does not open with the other person's account. A copy that someone has already downloaded cannot be taken back.
- **Recovery:** For a file you deleted or edited by mistake, check whether you can restore it from the service's Recycle Bin or version history. For OneDrive, this book confirmed the conditions in `[S13]` (time limit, no restore after permanent deletion). This book has not confirmed how to recover files in Google Drive.

## 7. Troubleshooting

| Symptom | Cause | How to fix it |
|---|---|---|
| Files are not syncing | Syncing is paused or you were signed out | Check the sync status in the program, then resume syncing or sign in again `[S11]` |
| Space on the computer suddenly dropped | A full copy was downloaded by mirroring | Check whether it is set to streaming or mirroring. Space on the computer and cloud storage space are different `[S11]` |
| Two files with similar names appeared | It may be a conflict copy | Compare the contents, keep only what you need, and tidy up with the `v` number |
| I deleted a file and it is gone from the cloud too | The deletion was reflected by sync | Check the service's Recycle Bin. OneDrive can restore within the time limit, and cannot restore after permanent deletion `[S13]` |
| I stopped sharing but the other person can still see it | It is shared through another path, or they already downloaded it | Check the other sharing paths (folder-level, link). A copy that was already downloaded cannot be taken back |
| The account is an organizational account, so installing or sharing is blocked | Administrator policy | Ask the administrator what is allowed, and if it is not allowed, do not do the optional exercise and replace it with the scenario exercise |
| I uploaded company material to a personal account | I uploaded before checking the tier and rules in CH03 | Do not hide it; tell the person in charge, and delete the file and stop sharing it (CH03, section 7) |
