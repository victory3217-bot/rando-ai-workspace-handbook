# CH02. Components and Overall Structure of an AI Workspace

## 2. Core Concepts

### 2-1. The five components

> **Author's interpretation** This book explains an AI Workspace by dividing it into the five parts below. This is the author's classification for teaching purposes, not a standard.

| # | Component | One-line description | Analogy |
|---|---|---|---|
| ① | PC and local files | The folders and files inside your own computer | The drawers of your own desk |
| ② | Cloud storage | A service that keeps files on internet servers and lets you use them from several devices | A shared cabinet |
| ③ | AI work environment | The AI service you use, and the settings, chats, and projects inside it | The person you hand work to |
| ④ | Work documents and knowledge base | The place where you gather work products, reference material, and frequently used templates and criteria | A document room |
| ⑤ | Work instructions and confirmation records | The rules the AI follows when you give it work, and the record of how you checked the result | A work manual and an approval log |

**How the five boxes connect to each other.**
- ① is the starting point where the originals are, and ② *syncs* ① to back it up and let you use it from several devices.
- ③ can read material in ① or ② and make a draft only after you paste it in, upload it, or connect it. You save the result back to ① yourself.
- ④ is where you collect useful work products and templates. It is usually a set folder inside ① or ②. Later you give it to ③ as reference material.
- ⑤ holds the rules you give to ③ and the record of what you checked. It is usually kept in the same folder as ④.

**Terms used in this chapter**
- **Sync (synchronization)**: A function that makes the other side match when you change a file on one side. You use it when you connect a folder on your PC to cloud storage.
- **Copy**: One more instance of the same file somewhere else. It is a cause of confusion about which one is the latest.
- **Knowledge base**: A folder or a set of documents where you organize material you will use again. It does not have to be a grand system; an *organized folder* is also a knowledge base.
- **Work instructions**: A document that writes down the rules to follow when you hand work to AI. CH10 covers this in depth.

It is important that ② and ③ are both *outside your own computer* (CH01, section 2-3).

### 2-2. How material moves

There are three main ways to give material to an AI service.

1. **Copy and paste** — You pick one part yourself and put it in.
2. **Upload a file** — You upload the whole file to the service.
3. **Connect** — You use a feature the service provides to let it reach cloud storage or another tool.

> **Author's interpretation** The further down the list, the more material can reach the AI service at one time. So the author considers the order in which *it is easiest to know what you are handing over* to be 1 → 2 → 3. Start with options 1 and 2, and use connection features only after you have set your information tiers in CH03.

Which connection features each service offers, and how, differs by service and changes over time, so this chapter does not explain them. CH06 and CH07 cover them with verification dates.

### 2-3. Each tool's role and data movement

When you draw your workspace map, be sure to write down *where copies are left behind* from the table below. If the same file stays in several places, it is hard to tell which one is the latest, and you will not know where to delete when you want to remove it.

| Component | What it does | How material comes in | How material goes out | Where copies are left behind |
|---|---|---|---|---|
| ① PC | Keeps the original working files | Creating them yourself, downloading | Cloud sync, uploading to an AI service | Inside the PC |
| ② Cloud | Backup, sharing between devices | Sync from the PC, uploading yourself | Downloading, share links | Cloud server + synced devices |
| ③ AI service | Receives instructions and writes drafts | Pasting, uploading, connecting | Copying the result and saving it on the PC | The service's chat history and so on (differs by service, CH03) |
| ④ Knowledge base | A collection of material to reuse | You move over the useful items from your work products | Giving it to the AI as reference material | Usually a set folder inside the PC or cloud |
| ⑤ Work instructions and records | Keeps rules and what you checked | You write them | Given to the AI along with the instructions | Usually the same place as ④ |

**Copy example:** If you save meeting notes in ① and ② syncs them, the same notes are in two places. If you paste these notes into ③, the content may also remain in ③'s chat history. Whether it remains, and how much, differs by service, so you check this in official documentation in CH03.

### 2-4. Seeing it on one workspace map

Draw the path one task takes as shown below. The arrows show the direction material moves.

```text
        ┌──────────────┐    sync     ┌──────────────┐
        │ ① PC·local files │ ◀────────▶ │ ② Cloud storage │
        └──────┬───────┘             └──────────────┘
   paste·upload │ ▲ copy result and save
               ▼ │
        ┌──────────────┐ reference material·rules ┌──────────────────┐
        │ ③ AI work environment │ ◀─────────── │ ④ Knowledge base       │
        └──────────────┘               │ ⑤ Work instructions·confirmation records   │
                                        └──────────────────┘
```

**Figure description (how to read it in words):** ① and ② sync with each other and exchange material. When you give ③ material from ① by pasting or uploading it, you copy the result ③ makes and save it in ①. ③ takes reference material and rules from ④ and ⑤ and uses them.

## 3. Workplace Application

Let's put the task of writing up meeting minutes, done by Gasang Han of the fictional company Example Trading Co., onto the workspace map. (All of this is a fictional setup.) This task is the same as candidate A (meeting minutes) in the CH01 writing example, and the *purpose of working with AI* written there was "reduce the burden of repetitive document work." The workspace map shows where material passes through in the task that serves that purpose.

| Step | What you do | Boxes passed through |
|---|---|---|
| 1 | Save the meeting notes in the `Meetings/2026-10` folder on the PC | ① |
| 2 | Paste the notes, with names and amounts masked, into the AI service | ①→③ |
| 3 | Save the draft you received on the PC, and check the decisions yourself | ③→① |
| 4 | Upload the checked final version to the cloud and share it with the team | ①→② |
| 5 | Save a useful minutes template and the rule "write decisions in a table" in the `Knowledge` folder | ①→④⑤ |

If you look for the missing box in this flow, Gasang Han has no *confirmation record* (⑤). If nothing records who checked what, it is hard to prevent the same mistake next time.

## 4. What You Need

- Account, permissions, cost: not needed
- Programs and files: A document program that can draw shapes or text boxes, or paper. You must be able to open the folders on your PC. You look only at **folder and file names, without opening the file contents**.
- Prior study: The document you made in CH01, especially candidate task A and the *purpose of working with AI*. **If you skipped CH01**, pick one task you would like to hand to AI right now and write one line each for "purpose of working with AI / input (what you give) / output / what a person checks."
- Time needed: about 40 minutes (the author's estimate; not tested with real learners)

## 7. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| One file seems to span several boxes | The same file is on the PC, in the cloud, and in chats | Decide on one place where the original is, and mark the rest as copies |
| I don't know what is in the cloud | You have never organized the sync folder | Write "Unknown" for now and organize it in CH05 |
| I don't know where copies are left behind (especially in AI services) | Each service stores data differently | Write "Unknown." CH03 covers how to check this in official documentation |
| I use several AI services | You use a different service for each purpose | In box ③, write one line per service. Be sure to distinguish personal accounts from company accounts |
| It is hard to tell ④ and ⑤ apart | Rules and material are mixed in one document | For now, it is fine to write them together in one box. You separate them in CH08 and CH10 |
