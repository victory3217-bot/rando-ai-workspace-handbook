## 2. Core Concepts

**Terms used in this chapter**
- **Project**: A ChatGPT feature that keeps related chats, files, and instructions in one place.
- **Project instructions**: Directions to ChatGPT that apply only inside that Project.
- **Project sources**: Files you upload to a Project or text you paste into it.
- **Memory**: A ChatGPT feature that remembers the content of earlier chats.
- **Prompt**: The request text you give to AI.

### 2-1. Basic ChatGPT environment

You can use ChatGPT in a web browser and in the mobile app (`[S6]` states that Projects are available on the web and in the mobile app). Once you are signed in, you can start a *regular chat*, ask questions, and upload files. A regular chat tends to end after one conversation, and each time you have to say again which files you gave and what instructions you set. A Project is the feature that *bundles these together for one task*.

### 2-2. The concept and role of a Project

> **Official documentation check — ChatGPT Projects, checked on 2026-10-26**
>
> - A Project keeps related chats, files, and instructions in one place, and lets ChatGPT use that context for ongoing work (writing, research, planning, and so on). `[S6]`
> - Projects and Project sharing are available to signed-in users and vary by plan and workspace settings. `[S6]`
> - To create a Project, select `New project` in the sidebar, enter a name, and choose an icon and color. `[S6]`
> - You can upload PDFs, spreadsheets, documents, and images to a Project, or paste in text. The number of files you can upload depends on the plan: Free 5, Go and Plus 25, Edu, Pro, Business, and Enterprise 40. You can upload 10 files at a time. `[S6]`
> - You add Project instructions under `•••` → `Project settings`. They apply only inside that Project and take priority over global custom instructions. `[S6]`
> - You can create as many Projects as you like, and there is no separate charge for using Projects. `[S6]`

> **Author's interpretation** A Project can be seen as the *place where you put* ④ (work documents) and ⑤ (work instructions document) into ③ (the AI work environment) from CH02. The instructions and templates you collected in the `04_AI_Instructions_and_Templates` folder in CH04 become the Project's instructions and sources. This mapping is the author's teaching interpretation and not wording from the official documentation.

### 2-3. How chats relate to Project knowledge, and memory

> **Official documentation check — Project memory and chats, checked on 2026-10-26**
>
> - A Project uses either default memory or project-only memory. You choose when you create it and can change it later in the Project settings (`Memory` in `Project settings`). A changed setting can take several hours to take effect. `[S6]`
> - With project-only memory, Project chats do not refer to previously saved memories, can refer to other chats in the same Project, and cannot refer to chats outside the Project. `[S6]`
> - What default memory refers to depends on the plan and settings. In Business and similar plans it can cross-reference chats outside the Project, while in Enterprise and Edu it stays inside the Project. `[S6]`
> - If you move an existing regular chat into a Project, that chat picks up the Project's instructions and file context. `[S6]`
> - A temporary chat cannot be added to a Project. If you save it, it becomes a regular chat and follows your account settings. `[S6]`

> **Author's interpretation** Learners using this for the first time are advised to choose *project-only memory*. The fictional data for candidate A will not mix with other chats, so the results are easier to interpret. The official documentation only describes how each setting behaves and does not recommend either one. Memory and data-training settings are separate issues, so look at the CH03 check table again.

### 2-4. Checking personal information and organization policy

Files and chats you put in a Project follow *the tiers and policies you set in CH03* as they are. A file does not become safe just because it carries the name "Project".

> **Official documentation check — Projects and data, checked on 2026-10-26**
>
> - In ChatGPT Free, Plus, and Pro, if the `Improve the model for everyone` setting is on, information accessed in a Project can be used for model training. `[S6]` `[S2]`
> - Data in a shared Project, on personal accounts, can be used to improve the model only if the Project owner and all participants have this setting on. `[S6]`
> - By default, data in ChatGPT Business, Enterprise, and Edu workspaces is not used for model training. `[S6]` `[S1]`
> - Deleting a Project permanently removes the chats and instructions in it and any files stored only in the Project, and this cannot be undone. Except where retention is required for legal or security reasons, it is removed from OpenAI systems within 30 days. `[S6]`
> - Project files can be viewed and downloaded by all Project members, not only the owner. `[S6]`
> - You can add Google Drive and Slack links to a Project as sources, and you must approve access when you connect them. `[S6]`

**What this chapter sets (the author's judgment):** ① This chapter does *not share* the Project. ② It does *not turn on* external connections such as apps or Google Drive. ③ It uploads fictional data only. ④ It does not write personal information, passwords, or API keys in the Project name or instructions. These items are there for the same reason as the "information not to enter" in CH03.

**Fictional AI output for the alternative path (it has deliberate errors).** Below is a *fictional AI draft* made to look like a summary of the fictional notes above. Compare it with the notes, find the errors, and write the verification record.

```text
[AI draft (fictional)]
| Item | Decision | Owner | Deadline |
|---|---|---|---|
| 1. Price reduction | Decided to send a reduction proposal to Client X | Associate B | By next Tuesday |
| 2. Vacation adjustment | Approved Staff C's November vacation | Manager A | Needs confirmation |
| 3. Next meeting | To be held on Wednesday of the fourth week of October | Needs confirmation | Fourth week of October |
```

> **Author's interpretation** The errors in the fictional draft above (the author's criteria, not an answer key): ① "Decided to send a reduction proposal": the notes say a *revised proposal* will be sent, and Manager A opposed the reduction. ② "By next Tuesday": the notes say "by next week". ③ "Approved the vacation" and "Owner: Manager A": the notes contain no approval decision. ④ "Wednesday": the notes say the date is to be decided. ⑤ "Open items: None": the substitute and the meeting date are undecided. ## 7. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| A menu such as `New project` does not appear | It depends on the plan, region, app version, and workspace settings `[S6]` | Trust the explanation on your own screen first, and if it is an organization account, ask the administrator. If it still does not work, use the alternative path (design sheet) |
| No more files can be uploaded | You hit the file limit for your plan (Free 5) `[S6]` | Delete files you do not need, or combine the material |
| You try to upload a file with the same name | A file with that name already exists | Choose `Upload anyway` or `Skip`, whichever appears on the screen `[S6]` |
| The AI writes things that are not in the notes | The instructions are weak or the material is ambiguous | Write "do not guess" specifically in the instructions, and add the mistaken cases to the instructions. Use only what a person has checked and corrected |
| Content unrelated to the Project gets mixed in | The memory setting, or you started from a regular chat `[S6]` | Start a new chat inside the Project and change memory to project-only. It can take several hours to take effect |
| You want to move a chat into a Project | It is a temporary chat, or a chat that cannot be moved `[S6]` | A temporary chat cannot be added to a Project, so start a new chat inside the Project |
| You uploaded material that should not have been uploaded | You uploaded before checking the tier | Do not hide it. Tell the person in charge and delete the file and the chat. Turning off the training setting alone does not delete it `[S2]` (CH03 section 7) |
