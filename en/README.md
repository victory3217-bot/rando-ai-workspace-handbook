# English edition / 영어판

**Status: not started. No English chapter is published.**

The Korean edition is written and reviewed first. An English chapter may be started only after the matching Korean chapter is `Reviewed`, and it is built into the site only when its status in `content-manifest.json` is `Reviewed` or `Published`.

- Chapter files go in `en/chapters/` with the same names as the Korean files (`CH01.md`, ..., `OP01.md`).
- Use the template `assets/templates/chapter-template.en.md`.
- Write for English-speaking general office staff (localize, do not translate word for word). Check tool menu names, account terms, and pricing in English for each tool and record the verification date.
- Do not machine-translate a chapter and publish it unreviewed.

영어 본문은 한국어 장이 `Reviewed`가 된 뒤에 시작한다. 이 폴더에 `chapters/` 파일이 없는 동안 사이트에는 영어 페이지가 생기지 않는다.
